# Experiment 11 – SQL Advanced Subqueries, DELETE & Analytical Queries

## Q1. Delete those employees who joined the company before 31-dec-1982 while their dept location is 'Mumbai' or 'Delhi'.

```sql
DELETE FROM EMP
WHERE HIREDATE < '1982-12-31'
  AND DEPTNO IN (
      SELECT DEPTNO
      FROM DEPT
      WHERE LOCATION IN ('MUMBAI', 'DELHI')
  );
```

## Q2. Display employee name, job, deptname, location for all who are working as managers.

```sql
SELECT E.ENAME, E.JOB, D.DNAME, D.LOCATION
FROM EMP E
JOIN DEPT D ON E.DEPTNO = D.DEPTNO
WHERE E.JOB = 'MANAGER';
```

## Q3. Display name and salary of FORD if his salary is equal to the high sal of his grade.

```sql
SELECT E.ENAME, E.SAL, S.HISAL
FROM EMP E
JOIN SALGRADE S ON E.SAL BETWEEN S.LOSAL AND S.HISAL
WHERE E.ENAME = 'FORD'
  AND E.SAL = S.HISAL;
```

## Q4. Find out the top 5 earners of the company.

```sql
SELECT ENAME, SAL
FROM EMP
ORDER BY SAL DESC
```

## Q5. Display the name of those employees who are getting the highest salary.

```sql
SELECT ENAME, SAL
FROM EMP
WHERE SAL = (SELECT MAX(SAL) FROM EMP);
```

---

## Q6. Display those employees whose salary is equal to the average of maximum and minimum salary.

```sql
SELECT ENAME, SAL
FROM EMP
WHERE SAL = (
    SELECT (MAX(SAL) + MIN(SAL)) / 2
    FROM EMP
);
```

## Q7. Display dname where at least 3 employees are working (display only dname).

```sql
SELECT D.DNAME
FROM DEPT D
JOIN EMP E ON D.DEPTNO = E.DEPTNO
GROUP BY D.DNAME
HAVING COUNT(*) >= 3;
```

## Q8. Display the names of managers whose salary is more than the average salary of the company.

```sql
SELECT ENAME, SAL
FROM EMP
WHERE JOB = 'MANAGER'
  AND SAL > (SELECT AVG(SAL) FROM EMP);
```

## Q9. Display those managers whose salary is more than the average salary of their employees.

```sql
SELECT M.ENAME AS MANAGER, M.SAL AS MANAGER_SAL
FROM EMP M
WHERE M.JOB = 'MANAGER'
  AND M.SAL > (
      SELECT AVG(E.SAL)
      FROM EMP E
      WHERE E.MGR = M.EMPNO
  );
```

## Q10. Display employee name, sal, comm and net pay for those employees whose net pay is greater than or equal to any other employee salary of the company.

```sql
-- Net pay = SAL + IFNULL(COMM, 0)
SELECT ENAME,
       SAL,
       IFNULL(COMM, 0)              AS COMM,
       SAL + IFNULL(COMM, 0)        AS NET_PAY
FROM EMP
WHERE (SAL + IFNULL(COMM, 0)) >= ANY (
    SELECT SAL FROM EMP
);
```
